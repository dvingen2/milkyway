Denne dokumentasjonen beskriver systemets kjerne: brand palette, tonale skalaer, surface-hierarki, state layers og modulære webkomponenter. Målet er at dokumentasjonen selv skal være den primære inngangen til systemet.

Kjernetesen

Digitale flater er meningsbærende objekter.

Systemet modellerer komponenter som overflater med eksplisitte roller, tydelig kontrast og separerte state-lag, slik at mening og adferd kan dokumenteres og gjenbrukes.

Dokumentasjonsområder

Systemet er strukturert som et sett med lesbare kunnskapsmoduler

Fundament

Arkitekturen går fra råmateriale til meningsbærende komponent

1. Brand palette

Systemets råmateriale er en nøytral ambient gråbase med teal som primær aksent og lilla som sparsom tertiær støtte.

2. Tonale skalaer

Tonale skalaer avleder semantiske fargeroller som --color-primary og et enklere hierarki av --layer-backdrop, --layer-surface og --layer-surface-1..4.

3. Roller og states

Innhold, overflater, outline og state layers skilles, slik at hover, focus, pressed, selection og activation kan eksistere side om side uten semantisk støy.

4. Komponenter

Web components kapsler interaksjon og markup, mens tokens og regler forblir globale, lesbare og portable.

Selection vs activation

Activation behandles som et handlingssignal, mens selection er en vedvarende informasjonstilstand. Dokumentasjonen skiller derfor eksplisitt mellom disse to lagene.

Dokumentasjonsprinsipp

  • Dokumentasjonen beskriver systemets hvorfor, ikke bare dets hvordan
  • Alle tokens skal kunne spores til et tydelig semantisk formål
  • Komponenter skal dokumenteres med anatomy, varianter og state-intensjon

    State Semantics

    State layers dokumenterer respons, fokus og vedvarende tilstand

    State Model

    Surface → content → interactive layer → selection/activation

    Dokumentasjonen skiller state-lagene fra overflatelagene. Basissurface bærer kontekst, innholdslaget bærer lesbarhet, og state-lagene uttrykker respons og vedvarende tilstand.

    1. Bruk hover og focus som tilbakemelding på mulighet og oppmerksomhet.
    2. Bruk activation for handling eller toggled energi.
    3. Bruk selection for vedvarende valgt tilstand, filtrering eller aktiv kontekst.
